# English Forge · 英语锻造所

一个离线优先的英语训练站，把词汇、听写、口语、阅读、语法和间隔复习放进同一套学习记录里。

## 已实现

- 基础高频词与考试词合并为 10,000+ 词条，支持看英想中、看中想英、双向四选一、拼写和听音写词六种训练。
- 词汇可按考试、词频、八类词性和六种学习状态组合筛选，并显示各分类实际词数。
- 每个词显示所属考试，考试总览展示已学和已掌握进度，词典同样支持考试筛选。
- 基于到期时间、错误次数和主观难度的复习队列，以及收藏词专项训练。
- 60 句听写与影子跟读、30 个口语任务、10 篇分级阅读和 24 节语法课。
- 阅读正文点词查义、即时语法检查、学习数据、连续天数与 JSON 导入导出。
- 阅读和语法错题进入统一回炉队列，重新答对后自动清除。
- 顺序感知的听写纠错、阅读收藏状态同步、深浅主题切换与单词键盘快捷键。
- 根据到期词、语篇错题、今日完成度和薄弱技能生成下一步学习建议。
- 手机与桌面自适应、浏览器朗读和 PWA 离线缓存。
- 学习记录仅保存在当前浏览器，不需要账号或服务器。

## 日常使用

本地完整版：

```bash
npm install
npm run serve
```

打开 `http://127.0.0.1:4174/`。也可以在 Finder 中双击 `打开英语锻造所.command`，脚本会在需要时启动本地服务并打开页面。

发给朋友或长期保存时，运行：

```bash
npm run release
```

单文件版位于 `release/English-Forge-英语锻造所.html`，不依赖网络、Node 或安装步骤，直接双击即可使用。语音识别由浏览器提供，部分浏览器会要求麦克风权限或联网。

## 开发检查

```bash
npm run check
```

该命令会重建词库，检查 10,000+ 词条与全部课程内容，运行浏览器 DOM 交互测试，并验证单文件版不依赖外部资源。

## 数据与隐私

高频词序和中英释义来自 MIT 授权的高频词项目，词频基础为 Peter Norvig 的英文语料统计，许可文件保存在 `data/source/HIGH-FREQUENCY-LICENSE.txt`。初中、高考、四级、六级、考研、托福和 SAT 标签来自 BSD-3-Clause 授权的 `KyleBing/english-vocabulary`，许可文件保存在 `data/source/exam/LICENSE.txt`。朗读使用浏览器原生语音；学习记录通过 `localStorage` 保存在本机。

应用代码的授权状态见根目录 `LICENSE.md`；第三方数据继续适用各自的许可证。
